# RAG with LangChain 🦜🔗

## Overview

This project implements a **Retrieval-Augmented Generation (RAG) pipeline**, combining document retrieval with AI-generated responses. It is a powerful tool to enhance corporate efficiency by enabling quick access to relevant documents, contracts or policies. Private companies benefit from secure, scalable knowledge management, reducing manual research time. 

## Key Component

| Component | Functionality |
| :---- | :---- |
| **LangChain** | Orchestrates the entire RAG workflow |
| **Hugging Face** | Provides embeddings (BAAI/bge-small-en-v1.5) and LLM (Mistral-7B-Instruct) |
| **Milvus** | Powers lightning-fast vector similarity searches |
| **Docling** | Handles document preprocessing and conversion |
